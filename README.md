# powder-play

スマートフォンのブラウザーで、空気・水・油・粉を動かして遊ぶ Canvas ベータ版
（v0.2）です。

## 起動

Node.js 22.17 以降と npm を使います。

```sh
npm install
npm run dev
```

本番ビルドの確認:

```sh
npm run check
npm test
npm run build
```

## Cloudflare Workers へのデプロイ

Cloudflare Workers のビルド・デプロイ設定は次のとおりです。

- ビルドコマンド: `npm run build`
- デプロイコマンド: `npx wrangler deploy`
- Worker と静的アセットのパスは [`wrangler.jsonc`](./wrangler.jsonc) で設定します。

## 操作

- **選択**: 粒子をタップし、選択グループをドラッグして移動
- **配置**: 選択中のグループを複製。未選択なら粉を配置。押し続けると約 120 ms 間隔で追加
- **流通**: 線を引き、始点から終点へ向かう短時間の流れを作る
- **二本指**: ピンチ／スライドでズーム／移動。回転で動作ダイアルを開き、指を離してモードを確定
- **ボタン**: 表示範囲（全体／幕裏）、一時停止、センサー有効化
- **キーボード**: 矢印キーで重力、`1`／`2`／`3` でモード、`+`／`-` でズーム、`Space` で一時停止

画面上の選択範囲は同じ物質の接触粒子（粒子間隔 2 セル以内、最大 256 個）です。粉と水は
空気より重く、油は水面に、粉は油面に残ります。空気の局所的な弱い反発は、物質の
境界でまれに空気セルを隣へ広げることで表現しています。選択中の粒子はシミュレーション
中もその場に固定され、空白をタップするか `Escape` キーで選択を解除できます。

初期配置では各物質層の粒子セル数を従来の約 1/4 にし、描画半径を約 2 倍にして見た目の
物質量を保っています。近傍の充填圧力はより広い範囲で計算し、離れた粒子も接触している
ように扱います。

## センサーと画面向き

センサーは「センサー有効化」ボタンから許可します。センサー権限には HTTPS または
localhost が必要です。iOS Safari など権限要求のあるブラウザーでは、ユーザー操作の
中で許可を求めます。向きのロックに対応しないブラウザーでは、向きが変わると一時停止
して元の向きに戻すよう案内します。センサーが使えない場合も矢印キーで遊べます。

## 開発時の確認

```sh
npm run check
npm test
npm run build
```

Android Chrome と iOS Safari のセンサー権限、複数指操作、画面向き、30 fps の実機
性能は、HTTPS 配信した端末で別途確認してください。

## 実験中: GPU 粒子操作

`/labs/mpm` は、合成粒子上でWebGPU操作を検証するGate 0の独立した実験画面です。
`/labs/mpm/kernels` は、Gate 1のMLS-MPM数値コア、Gate 2のGPU選択・局所力ドラッグ・
オブジェクト複製、Gate 4の水・油・弾性小石・破断固体3,674粒子の試作構成則を検証します。
いずれもWebGPU非対応のブラウザーでは利用できません。
通常のアプリ画面 `/` は従来のシミュレーションを引き続き使用します。実装状況と次の判定ゲートは
[2D GPU MLS-MPM ロードマップ](./docs/ROADMAP-MLS-MPM.md) を参照してください。

材料表現を深めるための [LiquidFun・MLS-MPMの４論点調査](./docs/RESEARCH-MLS-MPM-MATERIALS.md) と
[GPU材料表現の実装ロードマップ](./docs/ROADMAP-MLS-MPM-MATERIALS.md) も記録しています。
現行コードの確認結果と今後の実装提案を分けており、提案機能の実装・実機合格を示すものではありません。

[パフォーマンス計測・検討指針](./docs/PERFORMANCE-MLS-MPM.md) と
[チューニングの実装ロードマップ](./docs/ROADMAP-MLS-MPM-PERFORMANCE.md) は、
物理条件を固定した性能比較と数値・操作の回帰確認を扱います。

Gate 4ラボは描画目標を15・30・60・90・120 FPSから選べ、既定60 FPS・シミュレーション速度2×で開始します。速度は0.5×〜32×から選べます。
物理刻みは1/240秒に固定し、複数ステップを1つのGPU batchにまとめます。実際の描画FPSは画面のリフレッシュレートとGPU処理時間に制約され、フレーム間隔に合わせて1フレーム当たりのstep上限を調整します。
重力・速度・左右揺れ・一時停止などの操作は、PCではキャンバス横、狭い画面ではキャンバス直上に配置します。左右揺れは初期状態で停止し、ボタンで既定の±240 world units/s²・0.16 Hzを開始／停止できます。スライダーでは0〜360を調整でき、揺れはシミュレーション時間を基準としてbatchごとの時間平均加速度を適用します。
Gate 4の初期速度は水・油の各成分±8、小石の各頂点±30 world units/sの範囲から、シーン初期化ごとに独立した擬似乱数で割り当てます。小石は頂点速度差から初期角運動量を持ちます。
物理macrostepの基準は1/240秒で、CFL条件に応じて内部microstepに分割します。1 batch の初回処理上限は512 microstepで、CFL違反または診断可能な変形失敗は違反microstepをrollbackし、残り時間を細かい刻みで最大4回まで再試行します。通常処理とretryを合わせた上限は1,024 microstepです。固定macrostepが上限に収まらない高速度では、正のfloat32安全刻みまでmacrostep自体を短縮し、残り時間を保持します。処理上限超過による時間は自動で捨てず、要求倍率・実効倍率・未処理時間を画面に表示します。一時停止中には粒子状態を保ったまま未処理時間だけを明示的に破棄できます。安全な時間刻みを表現できない入力や回復不能な数値異常では停止し、初期シーンから再起動する操作を表示します。このCFL recovery経路は検証中であり、実機受け入れ済みの性能・安定性を示すものではありません。
emitterの初速に固定上限は設けず、追加前にfloat32/CFL安全性を確認します。処理可能な高速度は時間刻みを縮めるため、要求倍率より遅く進む場合があります。描画FPS、macrostep/microstep数、要求・実効時間倍率、未処理時間、submit換算の粒子更新量、CPU batch submit時間、GPU queue完了待ちを表示します。GPU queue完了待ちはGPU単体の実行時間ではありません。数値異常フラグは小さな状態だけを読み戻して確認します。一時停止中は連続emissionも停止します。
初期シーンは水2,000・油1,500・小石50個（各3粒子）・破断solid24粒子の計3,674粒子です。従来の14,696粒子から数を1/4にし、液体の格子間隔を9から18 world unitsへ広げ、粒子参照面積を25から100へ4倍にしました。液体密度と固体粒子質量も合わせて、各相の総質量・参照面積を保ちます。自由表面と診断マーカーは表示専用に面積をさらに2倍スケールし、粒子1個あたり旧scene比で約8倍の面積に見せます。小石は一辺132・中心間隔150 world unitsで液体上から内部へ広がります。水・油の自由表面は優勢な相の色で描き、等量に近い界面だけを明るく表示しますが、色表示は物理的な完全分離を意味しません。
GPU容量の上限は1,000,000粒子です。固定capacityのため、active粒子数を1/4にしても初期GPU buffer予約は大きく変わらず、retuned sceneのGPU buffer確保量は231,188,500 byteと実測しました。これは単一の描画なし診断profileであり、反復batch性能・端末別性能・持続性能は引き続き再測定が必要です。
応力・アフィン運動量は粒子ごとに１回計算し、16 MBのcacheをP2Gで再利用します。
物理dispatchの順序を保ったまま、batch内を１つのcompute passにまとめています。
初回CPU/GPU比較は水・油および小石群中央の液体接触を含む局所近傍だけを使い、
3,674粒子の全量readbackを避けます。
旧粉体6,000粒を含む20,000粒子版では、ローカルChrome WebGPUで既定重力90・速度2×の約60 simulated secondsを実行し、
初回CPU/GPU最大絶対誤差1.28e-5、数値エラーなしを確認しました。これは粉体・旧scene構成での歴史的記録です。
現行の小石は8列×7行（最終行2個）・中心間隔150 world unitsで配置し、正三角形の辺長132 world units（枠幅の6%）・λ=20・μ=10です。小石の三辺に位置制約を加え、水・油の相別格子法線接触、小石–液体の距離場接触と双方への反力、小石同士の三角形接触をGPUで解きます。
初回CPU/GPU比較は各材料の局所sampleです。CPU倍精度とGPU単精度の差を考慮し、速度には絶対・相対の誤差基準を使います。1,000,000粒子分の初期GPU確保量は221,564,392 byte（16 MBの粒子別応力cacheを含む）です。
これは限定的な接触prototypeです。接線摩擦、表面張力・濡れ・完全な界面分離、連続衝突検出、長時間の形状・運動量誤差は未検証または未実装です。三粒子は連続体メッシュではありません。
32×・100万粒子全数稼働・Android/iOS実機の持続性能と発熱も未確認です。
ドラッグは水の物理モデルではなくgrid上の局所力です。
